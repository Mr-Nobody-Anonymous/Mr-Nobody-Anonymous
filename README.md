## About

I'm a cybersecurity-focused technologist who enjoys building secure systems and learning how modern attacks work so I can defend against them. My work sits where **offensive security**, **threat modeling** and **applied AI** meet — from automated reconnaissance tooling to real-time computer vision and autonomous agent runtimes.

Three things shape how I work:

- **Security mindset** — threat modeling, least privilege, secure defaults and continuous hardening.
- **Curiosity by default** — CTFs, labs, reversing and practical experimentation over theory alone.
- **Builder's discipline** — automation scripts, tooling and web applications that people can actually use.

## Focus areas

| Direction | What it means in practice |
| :-- | :-- |
| 🔴 **Offensive security** | Reconnaissance, enumeration, web application testing and exploitation in authorised scopes |
| 🛡️ **Defensive engineering** | Threat modeling (STRIDE), logging and monitoring, incident-response fundamentals, baseline hardening |
| 🤖 **Applied AI** | Autonomous agent architectures, computer vision pipelines and automation that stays bounded and auditable |
| 🌐 **Secure development** | APIs, authentication and modern front-end workflows with security built into the design |
